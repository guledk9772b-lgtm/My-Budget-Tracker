# SpendWise Dashboard

SpendWise is a static financial dashboard shell created using HTML and CSS.

## Files

- `index.html` - Contains the dashboard structure, sidebar, header, and six financial category cards.
- `style.css` - Contains the Grid and Flexbox layouts, colors, typography, responsive design, card animations, and dark theme.

## Features

- CSS Grid dashboard layout
- Flexbox for sidebar, header, and cards
- Six financial category cards
- CSS custom properties for the theme
- Responsive layout below 768px
- Hover and keyboard focus effects
- Dark theme support

## Technologies

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Google Fonts
